# Demo Video Assets

Large demo videos are stored here locally but are ignored by git.

Recommended GitHub Release asset names:

- `demo-short.mp4`
- `demo-full.mp4`

Upload them to the latest release, then link visitors to:

```text
https://github.com/RealPapaya/VizCode/releases/latest
```

Direct asset links can also be used after upload:

```text
https://github.com/RealPapaya/VizCode/releases/latest/download/demo-short.mp4
https://github.com/RealPapaya/VizCode/releases/latest/download/demo-full.mp4
```
